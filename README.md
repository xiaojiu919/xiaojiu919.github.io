# 拾页 · 个人阅读手记

这是一个可直接发布的静态网站，完整内容在这个文件夹内；项目中的 `sources/` 参考资料不属于网站。

## 以后更新书单

把新书照片放进 `assets/covers/`，然后在 `books.js` 添加一条书目（书名、作者、分类、阅读日期、图片路径和感想）。更新 `books.js` 和封面到网站仓库后，GitHub Pages 会自动重新发布，网址保持不变。

你也可以在这个对话里继续发书名、照片和读后感，我可以帮你整理并更新网站仓库。GitHub 尚未连接，所以网站现在仍是本地版本。

## 固定网址

GitHub Pages 的免费个人网站地址格式为 `https://你的用户名.github.io/`。要使用免费方案，网站仓库需要公开；网站本身也是公开可访问的。请将仓库命名为 `你的用户名.github.io`，并在仓库设置中启用 Pages，来源选择 `main` 分支和仓库根目录。之后更新该仓库，Pages 会自动发布变更。
